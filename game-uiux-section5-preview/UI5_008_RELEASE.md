# UI5-008 — 캐릭터 표시 및 자동 전투 장면 추가
날짜: 2026-11-20

- Task ID: UI5-008
- 담당 섹션: 5번 UI/UX
- 변경 대상: 공개 UI 시연 사이트의 거점, 보관함, 원정 전투 화면
- 상태: 공개 시연 사이트 반영 및 테스트 완료 (게임 코어 통합 미완료)
- 변경 파일: `game-uiux-section5-preview/index.html`
- 변경 계약: 기존 UI5 mock transport 요청 타입·보상 계약 유지. 시연 한정 시각적 wave 2단계 및 자동 공격 타이머 추가. 공식 서버 전투 규칙 아님.
- 구현: 개척자 오리지널 임시 SVG, 균열 야수 임시 SVG, 스테이지별 색 조명, 전투 시 플레이어·적의 동시 표시, 체력바·타격/피격·피해 숫자, 자동 공격/기술 발동 및 전투 일시정지.
- 진입 동선: 홈에서 '자동 전투 장면 보기'로 진입. 기존 원정 입장 검증 API를 사용하며 S01로 시작.
- 장비 외형: 보관함에서 장착한 무기/방어구에 따라 개척자 프리뷰 CSS 변화; 실제 장착 상태는 UI5 mock transport의 상태 응답을 기준으로 반영.
- 테스트: Node.js 구문 검사 통과. jsdom DOM·자동전투·일시정지·승리·보상 검증 통과. Chromium 1365×840, 390×844, 320×720에서 거점 캐릭터 및 전투 양측 유닛 가시성·가로 넘침 없음·JavaScript 예외 0건 확인. 실제 브라우저에서 장검 제작→장착→거점 외형 갱신 통과.
- 다른 섹션 영향: 1번 코어(자동전투·상태 API), 7번 캐릭터 디자인(최종 아트 및 장비별 외형), 3번 밸런스/8번 데이터(정식 전투 수치·몬스터·스테이지)와 후속 연동 필요. 현재 해당 섹션 상태는 미확인.
- 차단된 의존성: 실제 캐릭터·몬스터 제작 자산, 공식 전투 틱/결과 스냅샷, 장비 외형 매핑 데이터 미확인.
- 다음 작업: 공식 스프라이트·애니메이션을 확인해 SVG 임시 자산 교체, 게임 코어 combat snapshot 및 equipment visual schema 연결.
- 주의: 본 화면은 HTML/CSS/SVG 기반 UI 시연용 장면이며 실제 게임 클라이언트 또는 서버 전투 엔진은 아님.
