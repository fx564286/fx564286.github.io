## 재현한 결함 (RED)

Chromium 320·390·768·1365px에서 사냥, 캐릭터, 원정, 제작, 장비 화면을 캡처하고 computed style을 측정했다.

- 동일 중요도의 버튼 높이가 37px, 40px, 43px, 44px로 서로 달랐음.
- 버튼 글자 크기가 11px, 12px로 제각각이었고, 보조 정보에 9~10px 텍스트가 혼재.
- 모바일 상단 `THE FRONTIER > 현재 화면` 경로가 여러 줄로 분리됨.
- 모바일 장비 섹션의 '제작소 열기' 동작이 섹션 제목과 수평으로 맞지 않음.
- 거점 SVG 캐릭터가 이동 버튼 영역에 겹쳐 보임.
- 모바일 하단의 버전/개발 안내가 부자연스럽게 한 줄로 붙어 있음.
- 원정 결과 버튼 크기/배치가 불규칙하고 전투 상태 배지가 320px에서 과도하게 줄바꿈.
- **TDD RED:** `ui5-011-visual-consistency.cjs` 최초 실행은 `--ui-space-4` 디자인 토큰 부재로 종료 코드 1. 별도 겹침 회귀는 거점 버튼과 캐릭터 SVG 교차 면적 2323, 2495(px²)를 재현하고 실패.

## 수정 사항 (GREEN)

### 디자인 토큰
- 간격: 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40px.
- 글씨: caption 11, secondary 12, controls 13, body 14, subsection 16, section 18, page heading 모바일 26·데스크톱 36px.
- 표준 작업 버튼 44px / 둥근 모서리 10px / 동일 패딩과 글씨 단계.
- 모바일 하단 네비게이션 5개 균등 셀, 각 64px. 데스크톱 메뉴 48px.
- 카드 모서리 14px, 모바일 패널 안쪽 간격 16px, 데스크톱 24px.

### 화면
- 사냥: 기본 조작 2열 버튼 정렬, 상태 표시 간결화, 전투 HUD 여백 통일.
- 캐릭터: 확대·교체 버튼 동일 치수, 장비 슬롯 타이포그래피/행 높이 통일.
- 원정: 구역 카드 동일 행 높이, 상세 정보 줄 맞춤.
- 제작: 재료·아이템 목록의 아이콘/설명/상태 배지 위치 및 폰트 통일.
- 장비: 장비 슬롯·인벤토리 행·보유 재료 정렬 통일.
- 거점: 캐릭터 SVG를 모바일 레이아웃 내 일반 흐름으로 내려 CTA와 겹치지 않도록 분리.
- 결과·모달: 44px 버튼, 모바일 2열 결과 행동 + 마지막 버튼 전폭, 설정 닫기 버튼 44px.
- 모든 모바일 페이지: 상단 화면 제목 한 줄, 섹션 제목과 조작 링크 동일 기준선, 안내 푸터 별도 행.
